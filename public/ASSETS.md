# public/ — brand assets

Drop the NexTake brand files here; the console picks them up automatically.

| File | Dimensions | Where it renders |
| --- | --- | --- |
| `icon.png` | square (e.g. 512×512) | UI logo lockup (rounded corners + hover micro-animation), browser tab icon, Apple touch icon |
| `header.png` | 1800×420 | Desktop banner on the public header and above the sign-in card |
| `footer.png` | 1800×500 | Brand showcase across the top of the public and admin footers |
| `icon.svg` | vector | Scalable NT mark — used as the fallback when `icon.png` is missing |

Until `icon.png` / `header.png` / `footer.png` are added, the UI renders
neutral navy placeholders instead of broken-image glyphs.
